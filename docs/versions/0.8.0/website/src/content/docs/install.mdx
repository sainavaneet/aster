---
title: Install Aster
description: Install, update, and verify Aster on Linux, macOS, and Windows beta.
---

Aster ships stable binaries for Linux and macOS. Native Windows support is preview-only beta.

## Install

On Linux or macOS, run:

```bash
curl -fsSL https://github.com/sainavaneet/aster/install.sh | sh
```

On Windows preview beta, install the preview channel:

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://github.com/sainavaneet/aster/install.ps1 | iex"
```

The installer downloads the right release binary for your platform and places it on your PATH. Aster defaults to preview on Windows without changing your config. The installer uses versioned install folders and updates a `current` junction, so updates do not need to overwrite a running `aster.exe`.

## Install with Homebrew

If you already use Homebrew:

```bash
brew install aster
```

## Install with mise

If you already use mise:

```bash
mise use -g aster
```

If mise reports `aster not found in mise tool registry`, update mise and retry. Older mise versions predate the Aster registry entry; `mise use -g github:sainavaneet/aster` works as a temporary fallback.

## Install with Nix

If you already use Nix, Aster provides a flake that builds Aster from source:

```bash
nix run github:sainavaneet/aster/v0.x.y
nix build github:sainavaneet/aster/v0.x.y
nix profile install github:sainavaneet/aster/v0.x.y
```

Replace `v0.x.y` with the latest release tag. You can omit the tag to track `master`, but release tags are recommended for normal installs.

The flake also exposes a development shell:

```bash
nix develop github:sainavaneet/aster
```

Update through the same Nix workflow you used to install Aster. For a profile install, list your profile entries and upgrade the Aster entry:

```bash
nix profile list
nix profile upgrade <index-or-name>
```

If Aster is an input in your own flake, update that input and rebuild your system, Home Manager, or development environment:

```bash
nix flake update aster
```

## Download manually

You can also download a binary from [GitHub releases](https://github.com/sainavaneet/aster/releases).

Choose the asset that matches your system:

| System | Asset |
| --- | --- |
| Linux x86_64 | `aster-linux-x86_64` |
| Linux aarch64 | `aster-linux-aarch64` |
| macOS Intel | `aster-macos-x86_64` |
| macOS Apple silicon | `aster-macos-aarch64` |

On Linux or macOS, make it executable and move it somewhere on your PATH.

```bash
chmod +x aster-linux-x86_64
mv aster-linux-x86_64 ~/.local/bin/aster
```

### Windows beta downloads

Windows binaries are published only on preview releases while native Windows support is in beta. Use the preview installer above for normal testing, or download the Windows asset from a preview GitHub prerelease:

| System | Asset |
| --- | --- |
| Windows x86_64 beta | `aster-windows-x86_64.zip` |

The archive contains `aster.exe` and its app-local ConPTY runtime. Keep the extracted directory together; do not copy only `aster.exe`.

## Verify

Start Aster:

```bash
aster
```

If your shell cannot find `aster`, restart the terminal or check that the install directory is on your PATH.

## Update

Aster checks for new releases and notifies you in the app. You can update manually:

```bash
aster update
```

`aster update` is for installs managed by Aster's own installer. Homebrew, mise, and Nix installs are updated through those package managers instead.

On Linux and macOS, Aster uses the stable update channel by default. To opt into preview builds from `master`, set the channel:

```bash
aster channel set preview
```

Switch Linux and macOS direct installs back to stable the same way:

```bash
aster channel set stable
```

For direct installs, changing channels also checks that channel and installs its latest binary. If that update fails, run `aster update` to retry from the configured channel.

Preview builds are manually published GitHub prereleases from the current development branch. They are useful when you want fixes before the next stable release, but they can regress. Homebrew, mise, and Nix installs do not use the preview channel.

Windows beta builds are preview-only for now. `aster channel set stable` is rejected on Windows until stable Windows releases are available.

By default, `aster update` installs the new binary and leaves compatible running sessions alone. If an update changes Aster's client/server protocol, Aster asks whether to stop the old server after installing. Stop the old server to use the new version. Stopping exits pane processes. For the default session, run `aster server stop`, then run `aster` again. For a named session, run `aster session stop <name>`, then run `aster session attach <name>` again.

To opt into experimental live server handoff for supported running sessions, run:

```bash
aster update --handoff
```

Live handoff does not apply to Homebrew, mise, or Nix package-manager updates. For those installs, update with the package manager, then restart that Aster session when you are ready to use the new server. If a running session still uses the old server, stop it with `aster server stop` or `aster session stop <name>`, then run Aster again.

## Requirements

Stable Aster releases support Linux and macOS. Native Windows builds are preview-only beta releases; see [Windows beta](/docs/windows-beta/) for supported workflows and known limitations.
